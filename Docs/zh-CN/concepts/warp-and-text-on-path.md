三个网格修改器在视觉元素生成网格之后重塑它，另有一个视觉元素画出供它们跟随的路径：

| 组件 | 作用 |
| --- | --- |
| `Warp`（`UDreamMeshModifierWarp`） | 按命名样式或贝塞尔晶格弯曲网格 |
| `Jelly`（`UDreamMeshModifierJelly`） | 按挂在弹簧上的晶格弯曲：会滞后、被按扁、回弹 |
| `Text On Path`（`UDreamMeshModifierTextOnPath`） | 把文字的字形排到圆、弧或路径上 |
| `Path`（`UDreamPath`，视觉元素） | 经过若干点的路径，可以画成线，也可以不画 |

它们和其它修改器一样（见[网格修改器与文字动画](mesh-modifiers.md)）：挂在视觉元素会生成网格的控件上——图片、纹理、精灵、
圆角矩形块、文字、线条。四个都在 `DreamGUIExtensions` 模块。

## 切细网格

矩形只有两个三角形，两个三角形弯不起来。变形或果冻在移动任何顶点之前，先把网格切成边长不超过 **Cell Length**（默认 8 个单位）
的小块：

- 轴对齐的矩形四边形——所有矩形写入函数、所有字形的四边形——**沿整张网格共用的一组网格线**切。共享一条边的相邻块（九宫格的九个部分）
  在这条边上的切点完全相同，弯曲后之间不会裂开。
- 其它三角形（圆环、多边形、线条的）切成规则的三角网格，每个三角形切成同样多的块。
- 每个新顶点的**所有属性**都按粗网格绘制时的插值方式得到：位置、法线和切线、颜色、四套纹理坐标和 UV4。所以圆角矩形块的圆角和描边、
  字形的距离场、图片的像素都会跟着网格一起弯。所有角都相同的值原样复制、不做混合：文字四边形的编码和圆角矩形块的数据行号会被
  逐位读回。
- 原有顶点保持下标不变，新顶点追加在后面，所以文字的字符顶点区间仍然指向字形的角（超链接仍然在字形所在处被点中）。
- **Max Vertices**（8192）限制切细后的顶点数：放不下就把格子放大，怎么也放不下就不切直接弯。

## Warp

| 属性 | 默认 | |
| --- | --- | --- |
| `Mode` | Style | `Style`（样式）或 `Lattice`（晶格） |
| `Style` | Arc | 下列 15 种之一 |
| `Orientation` | Horizontal | `Vertical` 让样式沿高度方向 |
| `Bend` | 50 | -100 到 100（百分比）；负值向反方向弯 |
| `HorizontalDistortion`、`VerticalDistortion` | 0 | -100 到 100（百分比）：一种透视，让右端（顶部）更大 |
| `Phase`、`PhaseSpeed` | 0、0 | Flag 与 Wave 样式的波相位（圈数），以及游戏运行时每秒转多少圈 |
| `LatticeColumns`、`LatticeRows`、`LatticePoints` | 4、4、均匀分布 | 晶格：每个方向 2 到 5 个控制点 |
| `Bounds` | Geometry | 被弯曲的框：视觉元素画出的内容的外框，或控件自己的矩形 |
| `CellLength`、`MaxVertices` | 8、8192 | 切细参数 |

样式按图像编辑器文字变形里的名字和顺序排列，这样文档里的变形可以按名字对上（`EDreamWarpStyle`，第一个是 `None`）：**Arc**（弧形）、
**Arc Lower**（下弧）、**Arc Upper**（上弧）、**Arch**（拱形）、**Bulge**（凸起）、**Shell Lower**（下贝壳）、**Shell Upper**（上贝壳）、
**Flag**（旗帜）、**Wave**（波浪）、**Fish**（鱼形）、**Rise**（增加）、**Fisheye**（鱼眼）、**Inflate**（膨胀）、**Squeeze**（挤压）、
**Twist**（扭转）。每种都是本插件自己的公式（`FDreamMeshDeform::WarpPoint`，注释写明各自的效果），看起来像编辑器里的同名样式，但
不逐像素一致。弯曲、两种扭曲和相位都可以做动画（控件动画的属性轨道、Tween、蓝图）。

**晶格**是张量积贝塞尔曲面：`LatticePoints` 从上到下逐行、每行从左到右，用框自己的度量——0,0 是左上角，1,1 是右下角，和图片像素的方向
一致。均匀分布时什么也不动。在设计器里选中控件，在视口中拖动它的控制网（品红色）上的点；一次拖动是一步撤销，按 Esc 恢复原位。

**静止时零开销**：不弯曲、不扭曲，或晶格没动过，变形既不切网格也不动顶点——小字号文字甚至仍然用覆盖率字形绘制。一旦弯曲，文字就改用
距离场，所有移动顶点的修改器都会这样。

### 用在文字上

在文字上，每个字形单独切细，再和其它字形一起弯曲：字形跟随整段文字所在的框（Bounds = Geometry 时就是字形墨迹的外框）。变形在
作用于字符的修改器之后运行，所以文字动画的位移也会被弯曲。

## Jelly

| 属性 | 默认 | |
| --- | --- | --- |
| `Columns`、`Rows` | 3、3 | 弹簧拉住的晶格 |
| `Frequency` | 4 | 每秒振动次数：越高越硬 |
| `DampingRatio` | 0.3 | 1 不过冲地停下，越小晃得越久 |
| `Inertia` | 1 | 控件自身的加速度推动控制点的程度 |
| `Anchor` | Centre | 哪里不动：Centre、Bottom、Top、Left、Right、None |
| `MaxStretch` | 0.3 | 控制点最多能被拉多远，按框较长边的比例 |
| `PressSquash` | 0.08 | 按住时控制点向按下点收拢的程度 |
| `DragStretch` | 0.4 | 拖拽时最近的控制点跟随拖拽距离的比例 |
| `Bounds` | Widget | 晶格覆盖的框 |

弹簧以固定的 1/240 秒为一步推进，与帧时间无关（半隐式欧拉，余下的时间留到下一帧），所以同样的帧序列在任何机器上晃得一样；
一帧超过 32 步就丢掉余数，而不是卡住追赶。`Simulate`、`Poke`、`SetPressed`、`DragTo`、`Settle` 可以手动驱动它。

按下和拖拽像传给被指针命中的控件上任何组件一样传给它——控件得能被命中——并且它会把事件继续传下去：它下面的按钮照样能点，它上面的
ScrollView 照样能滚。静止且没被碰时处于静止状态，开销和静止的变形一样：为零。

## 路径文字

| 属性 | 默认 | |
| --- | --- | --- |
| `Source` | Circle | `Circle`（圆）或 `Path`（路径） |
| `Radius`、`CircleCentre`、`StartAngle`、`SweepAngle`、`bClockwise` | 100、(0,-100)、-90、180、开 | 圆和其中一段弧，角度从十二点方向顺时针量；扫过 360 就是整圆，文字绕圆循环 |
| `PathWidget` | 无 | 视觉元素是要跟随的 `Path` 的那个控件 |
| `Align` | Centre | 对齐到路径的起点、中点或终点 |
| `StartOffset`、`OffsetSpeed` | 0、0 | 沿路径移动整段文字；游戏运行时每秒移动的单位数——跑马灯 |
| `LetterSpacing` | 0 | 字形之间额外加的间距 |
| `BaselineOffset` | 0 | 锚定线离开路径的距离 |
| `Anchor` | Bottom | 路径穿过字形的哪条线：Bottom（字立在路径上）、Middle、Top |
| `bFlip` | 关 | 让文字反方向走，排到路径的另一侧 |
| `bBendGlyphs` | 关 | 让每个字形沿路径弯曲，而不是整个转到路径方向 |
| `bHideOutside` | 关 | 在开放路径上，隐藏超出两端的字形，而不是让它们沿端点方向直着延伸 |

每个字形被放到路径上与它在原来那一行上同样远的位置，并转向路径在那里的方向。文字动画抬起的字形会离开路径抬起，转动的字形在路径方向
的基础上转动：路径文字在作用于字符的修改器之后、变形之前运行。用在非文字的元素上时，整个网格沿路径弯曲。

路径控件可以在树中任何位置：它移动或改变形状时，文字跟着变。

## Path

`UDreamPath` 是一个线条渲染器（有它自己的 `LineWidth`、画刷和颜色），经过本地空间中的 `Points`，`Linear`（折线）或 `Smooth`
（Catmull-Rom，两点之间分 `SegmentsPerSpan` 段），开放或 `bClosed`（闭合）。关掉 `bDrawLine` 时什么也不画，只作为路径。它在 `.dui` 里的标签是 `Path`。`GetLength`
和 `GetPointAtDistance` 供其它代码测量它。它的点和晶格的点一样可以在设计器里拖动（青色）。

## 修改器的运行顺序

修改器按阶段运行（`EDreamMeshModifierStage`，即修改器的 `GetStage`），同一阶段内按组件在控件上的顺序：

1. **Characters**——文字动画、渐变色、位置转 UV、蓝图修改器；
2. **Layout**——路径文字；
3. **Deform**——变形和果冻；
4. **Copies**——阴影、描边、长阴影：它们复制的是弯曲后的网格。

## 开销

- 静止的变形或果冻：零。弯曲时：切细后的网格——一个 200×60 的块、格子 8 时大约 200 个顶点而不是 4 个——每次视觉元素重建时都重算，
  文字也不再用小字号覆盖率字形。
- 相位动画、运动中的果冻、滚动的文字在运动的每一帧都重建视觉元素。
- 计算都在 CPU 上；不给绘制调用增加任何东西，变形后的元素照常合批。

## 限制

- 样式按名字看起来像图像编辑器里的，但不逐像素一致。
- 按矩形做点击检测的控件仍按矩形命中：把视觉元素的 Raycast Type 设为 **Mesh**（或 Visible Pixel），才会按弯曲后的形状命中。
- 剪贴到下方图层跟不了被修改器重塑过的元素（见[裁剪遮罩](clip-masks.md)）。
