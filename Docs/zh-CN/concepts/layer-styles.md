## 图层样式

`UDreamLayerStyle` 是一个行为组件，给控件加上图像编辑器那样的图层样式（`FDreamLayerEffects`）：

| 效果 | 参数 |
| --- | --- |
| 投影（可多个） | 混合模式、颜色、不透明度、角度（或全局光）、距离、扩展、大小、等高线、杂色、图层挖空投影 |
| 外发光 | 混合模式、不透明度、杂色、颜色或渐变、柔和或精确、扩展、大小、等高线、范围、抖动 |
| 内阴影（可多个） | 同投影，扩展改为阻塞 |
| 内发光 | 同外发光，源为边缘或居中，用阻塞 |
| 斜面和浮雕 | 内斜面、外斜面、浮雕、枕状浮雕、描边浮雕；平滑、雕刻清晰、雕刻柔和；深度、上或下、大小、软化、角度和高度、光泽等高线、高光与阴影的模式、颜色和不透明度、等高线和范围 |
| 光泽 | 混合模式、颜色、不透明度、角度、距离、大小、等高线、反相 |
| 颜色叠加（可多个） | 混合模式、颜色、不透明度 |
| 渐变叠加（可多个） | 混合模式、不透明度、渐变（颜色色标、不透明度色标、中点）、线性/径向/角度/对称/菱形、角度、缩放、偏移、反向、仿色 |
| 图案叠加 | 混合模式、不透明度、图案纹理、缩放、偏移 |
| 描边（可多个） | 大小、外部/内部/居中、混合模式、不透明度、用颜色、渐变或图案填充 |

样式本身还有 `Scale`（缩放所有大小和距离）、`FillOpacity`（只淡化控件自身的像素，效果不变）和全局光（角度、高度）。
数值与图像编辑器对话框里显示的一致——角度从右边起、逆时针、单位为度，大小用单位，百分比写成小数——所以从图像编辑器文件里
读到的样式可以逐字段对上。

从下往上，一个带样式的控件依次画：投影、外发光、控件本身（按填充不透明度）、图案叠加、渐变叠加、颜色叠加、光泽、内发光、
内阴影、描边、斜面浮雕。投影和外发光在控件后面；从叠加往上都在控件上、裁剪到控件，按各自的模式和控件混合。同一种有多个时，
后面的画在前面的上面。

**预设**（`UDreamLayerStylePreset`，数据资产）用来共享样式：引用预设的图层样式画预设的样式，并跟随预设的每次修改。
`DetachFromPreset` 把预设复制成控件自己的样式。

### 样式怎么画

由 DreamGUI 自动选择，无需设置（`UDreamLayerStyle::GetPath` 会告诉你走哪条）。

- **在元素自己的像素里**——RectBlock。着色器在 RectBlock 画到的地方精确测量它的圆角矩形，在同一个 pass 里画出全部效果，
  和 RectBlock 原本同批；四边形按效果的外扩撑大。样式记录放在 RectBlock 数据行里、RectBlock 自己的数据之后，只在有样式时
  上传：没有样式的 RectBlock 开销和以前一样。外部效果之间按各自模式混合，与背后按 Normal 混合——黑色投影用正片叠底和用
  Normal 看起来一样。带图案的样式改走「单独绘制」，那里能绑定图案纹理。
- **单独绘制**——其它所有控件：文字、图片、精灵、没有自身视觉元素的控件（整棵子树）、单独绘制的图层组（子树）。它画的内容
  先进自己的纹理（和图层组一样），对纹理 alpha 做跳跃泛洪（jump flood）得到每个纹素到边缘的距离，再按距离把样式画成控件
  放下时的几层——每个外部效果按自己的模式叠在背后之上，然后是带效果的控件本身，按图层组的模式、不透明度和遮罩。这对背后
  是精确的，对任意形状都成立；代价是组纹理、泛洪（纹理尺寸每个二次幂一个 pass）、一个样式 pass 和每层一次合成，每帧都有。
  只在能单独绘制组的画布上生效（见[混合模式与图层组](blend-modes-and-groups.md)），其它地方不画样式。

单独绘制时测量的形状是控件 alpha 不低于一半的地方：完全半透明的控件不出投影。渐变和图案铺在控件的矩形上。

### RectBlock 自带的效果

RectBlock 一直有自己的外阴影、内阴影、描边和本体渐变。它们是图层样式里四种效果的另一种写法：`GetEffectsAsLayerStyle`
把它们写成样式（外阴影→投影，内阴影→内阴影，描边→内部描边及其渐变，本体渐变→径向渐变叠加），`SetEffectsFromLayerStyle`
把样式里第一个投影、内阴影、描边和渐变叠加写回去。它们表达不了的（混合模式、等高线、杂色、外部描边）会丢掉。RectBlock
照旧自己画这些效果，与以前逐像素一致；控件上的图层样式叠加在它们之上。

## 形状融合

`UDreamShapeBlendGroup` 是挂在容器上的行为组件，把子项里的 RectBlock 融成一个形状：它们的圆角矩形用宽 `Smoothness`
单位的平滑最小值连起来，靠近的两个会流到一起。每个子项按自己 RectBlock 的 `ShapeBlendOperation` 加入：并集、相减或相交，
按子项顺序。形状上的颜色是成员的本体颜色，按每个成员在该处对形状的贡献混合；成员的贴图和它自己的描边、渐变、阴影不画。

成员不再各自绘制：第一个成员用一个覆盖所有成员的四边形画出整个形状，走内置着色器或它的材质，和普通 RectBlock 一样合批。
组所在控件上的图层样式在同一批像素里围绕融合后的形状绘制。移动子项，形状随之变化。点击落在离点最近的成员上，前提是融合后
的形状覆盖该点——CPU 用的是着色器同一公式。最多 32 个成员。

`MakeShapeInFrame` 把融合后的形状换到另一个控件的坐标里，供着色器读取（`DreamUIShapeBlend.ush`）：玻璃就是这样从融合组
取形状的（`UDreamGlass` 的 `Shape` 设为 `ShapeBlend`，见[玻璃](backdrop-effects.md)）。

## 光与全息箔

- **`UDreamPointerLight`**（挂在容器或画布根上）是一盏跟随指针的小光，也可以固定位置或用动画驱动：颜色、强度、半径和离控件
  的高度。它从自己所在的位置照亮其下所有图层样式的斜面（代替样式自己的光照角度），并把其下所有有描边的 RectBlock 的描边渐变
  中心放到自己身上——Reveal 式描边高光，开销只是 RectBlock 的一行数据。跟随指针时，指针在其控件平面且在照射范围内时淡入，
  离开时淡出，所有东西回到自己的光照。
- **`UDreamTiltCard`** 让控件带弹簧地朝指针 3D 倾斜，指针下的边往后沉，指针在上面时略微放大；走渲染变换，不影响布局。放进
  透视作用域（父级打开 `Perspective`）才有透视缩短。
- **`UDreamHoloFoil`**（挂在图片、精灵、纹理或 RectBlock 上）让元素用一个材质绘制，叠加闪卡的全息箔：随视角滑动的彩虹条纹、
  横扫卡面的高光、随转动闪烁的亮点，范围由遮罩决定。视角取指针相对中心的偏移、同一控件上倾斜卡片的倾斜，或手动设置。材质
  （`DreamUI_HoloFoil`、`DreamUI_HoloFoilRect`）由 DreamShader 从 `DShader/` 生成；材质单独一个 draw call。
