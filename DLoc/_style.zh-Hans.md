These are the texts of an Unreal Engine editor plugin (DreamGUI, a UI framework): menu items, buttons, panel and property
names, tooltips, dialogs and messages. Translate them the way the Unreal Editor's own Simplified Chinese does.

- Short labels (menu items, buttons, property and category names) stay short: a few characters, no full stop, no 您.
- Tooltips and messages are plain, complete sentences in a neutral, technical register.
- Keep code as it is: identifiers, file extensions (.dui, .uasset), `backticked` text, paths, console commands, and
  C++ or Blueprint names written in CamelCase.
- Keep product and format names in English: DreamGUI, UMG, Slate, PIE, RHI, MSDF, Niagara, PSD, Sequencer.
- Use Chinese punctuation in Chinese sentences (，。：；（）), but leave punctuation inside code alone.
- Do not add a space between Chinese and English words.
